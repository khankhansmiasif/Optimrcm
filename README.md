# Optim RCM Billing Website

A responsive static website starter for Optim RCM Billing, built with HTML, CSS, and vanilla JavaScript.

## Files
- `index.html` — website content and page structure
- `style.css` — responsive layout and visual styling
- `script.js` — mobile navigation and consultation email form

## Before publishing
1. Confirm your company email and update `info@optimrcmbilling.com` in `index.html` and `script.js`.
2. Add your real company phone number, address (if desired), social links, and approved testimonials.
3. Replace illustrative dashboard visuals/text with genuine, authorized content if desired.
4. The contact form currently opens the visitor's email app; connect a secure form service/backend to receive submissions directly.
5. Do not collect patient health information through this general contact form.

## Preview
Open `index.html` in a browser.
